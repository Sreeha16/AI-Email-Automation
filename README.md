# AI-Email-Automation
This project is an automated workflow that connects Gmail, Google Gemini AI, and Twilio to ensure no critical email goes unnoticed. It monitors incoming emails, summarizes their intent using advanced AI, and sends an immediate, concise SMS notification to the recipient.
🛠️ Tech Stack
 Make.com: Logic and workflow orchestration.
 Gmail API: Automated email monitoring.
 Google Gemini AI: Intelligent content analysis and summarization.
 Twilio API: SMS notification delivery.
💡 The Problem Solved
Small business owners often miss urgent inquiries because they are away from their computers. This system acts as a "virtual assistant," filtering noise from important leads and delivering summaries directly to the owner's pocket.
⚙️ How to Deploy
1. Export the ⁠blueprint.json⁠ file provided in this repository.
2. Import the file into your own Make.com account.
3. Configure your API keys for Gmail, Gemini, and Twilio within the modules.
4. Activate the scenario to start monitoring.
